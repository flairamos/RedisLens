# RedisLens v1.0.0

> 面向开发与运维的一站式 Redis 可视化管理平台 —— 让数据看得见、改得动、管得住。

首个正式版本，覆盖产品 PRD V1.0 全部 P0 功能与 V1.5 增强。

## ✨ 功能

- **连接管理**：多实例登记与分组、SSH 隧道、TLS 加密、哨兵 / 集群模式、一键只读模式、心跳探活与断线自动重连
- **数据浏览与编辑**：键空间树（懒加载）、SCAN 游标分页（禁用 KEYS 全量扫描）、模式/类型筛选、五大类型 + Stream + RedisJSON 的查看与行内编辑、保存前 Diff 预览、十万键级虚拟滚动
- **TTL 管理**：TTL 可视化、批量续期、移除 TTL（永久键正确显示）
- **监控仪表盘**：INFO 周期采样（默认 10 秒）、QPS / 命中率 / 内存 / 碎片率 / 连接数 / 网络 IO 曲线、时间窗口回看与缩放
- **命令行控制台**：语法高亮、命令 + 键名自动补全、会话历史、危险命令强制拦截与二次确认（FLUSHALL / CONFIG / SHUTDOWN 等）
- **键空间分析**：大 Key 排行（内存 / 元素）、类型与 TTL 分布、慢查询日志、热命令统计
- **数据导入导出**：JSON（含 DUMP 保真数据，可跨实例恢复）/ CSV 导出、导入、批量删除预览确认
- **发布订阅**：频道 / 模式订阅、实时消息流、消息发布
- **实例拓扑**：单机主从 / 哨兵 / 集群分片自动发现
- **安全与审计**：连接凭据 AES-256-GCM 本地加密（密钥机器绑定派生）、危险命令白名单拦截、操作审计日志（月度轮转，留存 ≥ 90 天）、回收站（删除键 DUMP 备份一键恢复）
- **体验**：浅色 / 深色主题一键切换、三档列表密度、`Ctrl+K` 全局搜索（键 / 命令 / 模块）
