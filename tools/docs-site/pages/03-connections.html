RedisLens 把「一个 Redis 实例的访问方式」保存为一条连接：地址、认证、网络隧道、 安全选项与只读策略都在这里配置。连接可以被分组、测试、复用，并在打开后自动探活。

连接模型

所有连接保存在本地 config.json 中，默认按「分组 → 名称」排序。 同一台 Redis 可以登记多条连接，例如：

  • 「生产-订单缓存（只读）」与「生产-订单缓存（运维）」使用不同权限的 ACL 账号；
  • 「开发」与「测试」使用不同分组，在顶部实例切换器中分开展示；
  • 同一条连接既可以从本机直连，也可以改为 SSH 隧道访问，无需重新登记实例。
连接与实例是两件事
连接只是访问配置，不包含 Redis 数据。删除连接只会清理本地凭据与设置， 不会删除、清空或修改服务端任何键。

保存、测试与生效

  1. 填写并测试 「测试连接」会用当前表单（未保存也可以）建立一次临时连接，返回版本、角色、模式、 内存与键总数；测试不会写入配置。
  2. 保存 保存会加密凭据并写入 config.json。
  3. 打开 在列表点击「连接」，或双击实例卡片。打开成功后会跳转到数据浏览页。
修改已打开的连接需要重连
已打开连接使用打开时的配置快照。修改地址、密码、TLS 或只读等设置后， 请先「断开」再「连接」，新配置才会生效。

单机模式

适合单节点 Redis，也适合「主从架构但直接连主节点」的场景。填写地址、端口与 DB 后测试即可。 主从信息可以在 实例拓扑 中查看，读写仍走当前连接的主节点。

哨兵模式（Sentinel）

哨兵模式由哨兵返回当前主节点地址，RedisLens 使用 go-redis 的 Failover 客户端自动跟随主从切换。 选择模式为「哨兵」后需要额外填写：

字段说明
主库名称（master name）哨兵中登记的主节点名称，例如 mymaster。
哨兵地址一个或多个 host:port，用英文或中文逗号分隔，例如 10.0.0.1:26379, 10.0.0.2:26379。
哨兵用户名 / 密码哨兵自身启用 ACL 或密码认证时填写；Redis 数据节点的认证仍使用上方「用户名 / 密码」。
  • 实际连接的主节点由哨兵返回，列表里的地址 / 端口只作为实例标识展示。
  • 至少填写一个可达的哨兵地址；所有哨兵都不可达时，打开连接会失败。
  • 主从切换期间连接可能短暂中断，后台心跳会自动重连。

集群模式（Cluster）

选择「集群」后填写任意一个种子节点地址与端口。RedisLens 会通过 CLUSTER SLOTS 发现完整分片，并在收到 MOVED / ASK 重定向时自动路由。

  • 集群只支持 DB 0，表单中的 DB 会被锁定为 0。
  • 种子节点只需一个；建议选择稳定的节点，避免使用临时扩缩容节点。
  • 跨槽位的多键命令可能因键不在同一槽而失败，这是 Redis Cluster 的限制，不是客户端错误。
  • 分片与槽位分布可在 实例拓扑 中查看。

SSH 隧道

当 Redis 只监听内网或本机回环地址时，可以通过跳板机建立 SSH 隧道。开启后填写：

字段说明
SSH 主机 / 端口跳板机地址，端口默认 22。
用户名SSH 登录用户。
认证方式密码 或 私钥。
SSH 密码密码认证时使用，保存后加密。
私钥路径 / 口令私钥认证时选择 OpenSSH 或 PEM 格式私钥文件；私钥有口令时填写口令。
Redis 地址是「从跳板机看」的地址
隧道建立后，RedisLens 会通过 SSH 服务器拨号到连接中填写的 host:port。 如果 Redis 只监听跳板机本地，地址应填 127.0.0.1:6379，而不是你本机看到的地址。
SSH 主机指纹不校验
当前版本不维护 known_hosts，也不会验证 SSH 服务器主机密钥。 请只在可信网络中使用 SSH 隧道，或通过堡垒机与网络策略控制风险。 详见 安全与审计 · SSH 边界。

TLS 加密

Redis 服务端启用 TLS 时，打开「TLS 加密」并按需配置证书。最低协议版本为 TLS 1.2。

字段说明
CA 证书自定义 CA 的 PEM 文件。指定后使用该 CA 校验服务端证书。
客户端证书 / 私钥双向 TLS（mTLS）时使用，两者需同时提供。
SNI 服务器名证书域名与连接地址不一致时指定。
跳过证书校验仅用于自签证书或测试环境。生产环境开启会让中间人攻击无法被发现。
不要在生产环境跳过证书校验
「跳过证书校验」会关闭服务端身份验证。若只是自签证书，优先把 CA 证书导入并填写「CA 证书」。

只读模式

只读模式是一道双向防线：界面会隐藏或禁用写操作入口，后端在执行前也会再次校验。 推荐对生产环境默认开启。

  • 数据浏览：新建键、批量续期、移除 TTL、批量删除、值编辑、重命名、删除等入口被禁用或隐藏。
  • 控制台：写命令与未知命令被拦截；只读命令正常执行。
  • 导入、发布消息、回收站恢复等写操作同样被阻止。
  • 只读模式不影响监控、拓扑、慢查询、审计查询等读取能力。

连接列表中会显示 🔒 只读 标记，状态栏也会标注「只读」。

打开、关闭与状态

心跳与自动重连

  • 连接打开后每 5 秒 PING 一次，状态点实时反映 ok / down / connecting / closed。
  • 断线后按 1 秒、2 秒……递增退避（单次上限 15 秒）重连，最多约 30 次；之后停止自动重连，需手动操作。
  • 重连成功后监控采样会自动切换到新客户端，无需重新打开页面。
  • 关闭连接会停止心跳、监控采样与 Pub/Sub 订阅，并释放 SSH 会话与连接池。

切换数据库与实例

  • 顶部「DB」选择器可切换 0 – 15；每个 DB 使用独立的客户端缓存。
  • 集群模式固定 DB 0，顶部显示「DB 0 · Cluster」。
  • 切换实例后，键空间树、键列表、监控与分析会按新连接重新加载。
  • 切换 DB 后键空间树会重置；键列表与值查看器不会自动清空，请先点键列表的刷新按钮，再执行编辑或删除。
  • 顶部实例切换器按分组列出所有连接与健康状态，可直接切换；未打开的连接会先尝试打开。

删除连接

删除连接会先关闭它，再从 config.json 中移除配置与加密凭据。 该操作不影响 Redis 服务端数据，但不可撤销；如需保留配置，请先备份数据目录。

常见配置组合

场景模式关键配置
本机开发 单机 127.0.0.1:6379，DB 0，无密码。
内网生产（只读巡检） 单机 ACL 只读账号 + 只读模式；如需远程访问再加 SSH / TLS。
云托管 Redis 单机 开启 TLS，填 CA 或使用系统信任链；按服务商要求填写 ACL 用户名。
哨兵高可用 哨兵 master name + 全部哨兵地址；哨兵与数据节点认证分开填写。
集群 集群 任意种子节点；DB 固定 0；跨槽多键命令需自行拆分。
仅跳板机可达 单机 / 哨兵 / 集群 开启 SSH 隧道；Redis 地址填跳板机视角的地址。
