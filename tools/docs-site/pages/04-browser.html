数据浏览是 RedisLens 的核心工作区：左侧用键空间树定位前缀，中间用 SCAN 游标浏览键， 下方查看并编辑值，右侧展示键详情与 TTL。所有遍历都避免使用会阻塞实例的 KEYS 全量扫描。

工作区布局

进入「数据浏览」后，界面分为四个区域：

  • 左侧键空间树：按 : 分隔的键前缀组织，懒加载子层级；点击前缀即按 前缀:* 过滤键列表。
  • 中间键列表：展示匹配模式下的键、类型、TTL 与内存大小，支持多选与批量操作。
  • 下方值查看器：根据类型渲染编辑器，支持行内修改与保存。
  • 右侧键详情：键名、类型、内部编码、大小、元素数、TTL，以及 TTL 编辑、重命名、删除入口。
当前实例与 DB 始终可见
顶部实例切换器显示连接名与健康状态，状态栏显示 host:port DBn · 模式 · 只读。执行任何写操作前，先确认这两个位置。
切换 DB 后请先刷新
顶部的 DB 选择器会改变后续操作的目标库，但当前键列表与已打开的值不会自动清空。 切换 DB 后请先点键列表的刷新按钮，再查看或编辑值，避免把上一个 DB 的数据写到新 DB。

键空间树

键空间树把形如 user:1001:profile 的键按前缀拆成层级，适合在几十万键中快速缩小范围。

  • 首次进入时加载根层级；展开节点时才按前缀请求子层级（懒加载）。
  • 点击某个前缀，键列表的匹配模式会变为 该前缀:* 并立即刷新。
  • 点击「全部键」恢复 *。
  • 「刷新树」会清空已展开缓存并重新加载根层级，适用于键空间结构变化后。
  • 切换实例或 DB 时，树会自动重置。
前缀分隔符
树按冒号分层，因此 order:2026:01 会归入 order 分支。 如果业务键大量使用其他分隔符（如 user.1001），树的聚合效果会弱一些， 此时直接用键列表的模式筛选更高效。

键列表与 SCAN 分页

键列表使用 SCAN 游标渐进遍历，不一次性拉取全部键。每次扫描的 COUNT 由设置中的 SCAN COUNT 决定，默认 500。

控件行为
匹配模式 支持 Redis glob（*、?、[abc]）。输入后按回车生效；默认 *。
类型筛选 按 string / hash / list / set / zset / stream / json 过滤，选择后立即刷新。
刷新 从游标 0 重新扫描，并清空当前选择。
滚动加载 列表使用虚拟滚动渲染；底部显示已加载键数与当前游标，点「加载更多」继续下一页。
多选 左侧复选框支持单选、全选当前已加载的键，用于批量续期、移除 TTL 与删除。

列表字段

  • 键名：等宽字体展示，点击载入值；当前键以红色高亮。
  • 类型：带颜色的类型徽标，包含 RedisJSON 的 JSON。
  • TTL：永久 表示无过期；剩余不足 60 秒时以琥珀色提示；0s 表示即将过期。
  • 大小：MEMORY USAGE 结果，未知时显示 -。
SCAN 不保证快照一致性
SCAN 是增量遍历：遍历期间新增或删除的键可能被返回、重复返回或漏掉。 它适合浏览与巡检，不适合需要严格快照的一次性导出；导出逻辑同样基于扫描， 因此导出期间应避免大量写入。

全局搜索（Ctrl+K）

按 Ctrl + K 打开全局搜索，可同时检索功能模块、键名和命令：

  • 输入模块名（如「监控」「审计」）直接跳转对应页面。
  • 输入键名片段，会以 *片段* 做一次 SCAN（最多 30 条），回车打开该键。
  • 输入命令名（如 HSET），回车跳到控制台并填入命令前缀。
  • 方向键选择，Enter 打开，Esc 关闭。

查看与编辑值

选中键后，值查看器顶部显示类型、键名、元素数 / 字节数、内部编码与刷新按钮。 不同数据类型的编辑方式如下：

类型查看编辑操作
String 文本编辑区；合法 JSON 可切换「格式化 / 原始」。 直接修改文本后保存。保存前会弹出 Diff 预览；SET 后自动恢复原 TTL。 非 UTF-8 内容以 Base64 展示，保存时按 Base64 解码写回。
Hash 字段与值表格，按字段名排序；显示完整字段集合。 「+ 字段」新增；双击值行内编辑后回车保存；行尾删除按钮删除字段。
List 按下标展示（首次加载前 500 个元素），支持下标定位。 「左侧插入 / 右侧追加」；双击元素编辑；删除元素； 下标定位仅在已加载范围内有效。
Set 成员列表（首次加载 500 个），按字典序展示。 「+ 成员」新增，一行一个成员可批量添加；行尾删除成员。
ZSet 按排名展示前 500 个成员与分数。 「+ 成员」添加成员与分数；双击分数行内修改；行尾删除成员。
Stream 前 200 条消息的 ID 与字段键值对。 「+ 消息」新增，ID 留空由服务端生成（*）； 字段按「每行 key=value」填写；行尾删除消息。
JSON RedisJSON 文档，格式化 / 原始视图切换。 编辑整个 JSON 文档后保存到根路径 $。需服务端加载 RedisJSON； 非法 JSON 会被服务端拒绝并返回错误。
集合类型是「分页视图」，不是全量视图
List / Set / ZSet 首次只加载前 500 个元素，Stream 只加载前 200 条； Hash 使用 HGETALL 返回全部字段，超大 Hash 可能带来明显开销。 超大集合建议配合控制台按需读取。

二进制值

当字符串、Hash 字段或 List 元素不是合法 UTF-8，或包含 NUL 字节时，值查看器会显示 二进制（Base64 展示），并以 Base64 文本呈现。 编辑后保存时按 Base64 解码写回；请确保修改后的内容仍是合法 Base64。

保存前 Diff 预览

编辑 String 或 JSON 并点击「保存」时，会先弹出左右对照的变更预览： 左侧为当前值，右侧为即将写入的新值。确认后才真正执行写入，取消则保留编辑内容。

Diff 只覆盖字符串类值
Hash、List、Set、ZSet、Stream 的行内编辑是逐条立即写入的，不会经过 Diff 确认。 对生产数据做批量修改时请格外小心。

TTL 管理

单个键

右侧键详情提供 TTL 编辑：

  • 输入秒数并点「续期」，会执行 PEXPIRE。
  • 点「永久」会移除过期时间（PERSIST），键变为永久存活。
  • TTL 显示为 永久 表示 -1；不存在 表示键已不存在。

批量操作

在键列表中勾选多个键后，工具栏提供：

  • 批量续期：输入秒数，对所有选中键执行 PEXPIRE。
  • 移除 TTL：二次确认后对所有选中键执行 PERSIST。
  • 两个操作都会写入审计日志（key_edit），移除 TTL 记为 warn 级别。

新建键

工具栏「新建键」打开创建对话框，字段包括键名、类型、初始值与 TTL：

类型初始值如何写入
string作为字符串值写入。
hash初始值写入字段 field1。
list初始值作为第一个元素追加到右侧。
set初始值作为第一个成员。
zset初始值作为成员，分数固定为 1。
stream初始值写入字段 field1 的第一条消息。
json初始值必须是合法 JSON 文档，写入根路径。
  • TTL 单位为毫秒；留空表示永久。
  • 创建成功后列表自动刷新并打开该键。
  • 只读模式下「新建键」按钮禁用，后端也会拒绝创建。

重命名与删除

重命名

键详情中的「重命名」执行 Redis RENAME。如果目标键已存在， 会被直接覆盖，且没有额外确认。重命名前请确认目标键名。

删除与回收站

  • 单个键删除、批量删除都会先 DUMP 备份到当前连接的回收站，再执行 UNLINK。
  • 删除前会弹出确认框；批量删除显示选中数量。
  • 删除成功后可到 回收站 恢复；回收站为内存态，容量 100 条 / 64 MB。
  • 删除与恢复都会写入审计日志（key_delete）。

只读模式下的行为

连接开启只读后，以下入口会被禁用或隐藏：新建键、批量 TTL、移除 TTL、批量删除、 值编辑、重命名、删除键。后端在执行写操作前还会再次校验连接状态， 即使绕过界面调用也会被拒绝。
