这里汇总连接、权限、导入导出与数据目录相关的常见问题。如果仍未解决， 请在 GitHub Issues 中附上错误信息、Redis 版本与连接模式。

连接问题

提示连接被拒绝或超时

  • 确认地址、端口正确，且 Redis 进程正在监听；默认端口为 6379。
  • 确认 Redis 的 bind 与 protected-mode 允许来自本机的连接。
  • 检查本机防火墙、云安全组、Docker 端口映射或 NAT 是否放通。
  • 远程实例只开放内网时，使用 SSH 隧道；Redis 地址要填「从跳板机看」的地址。
  • 连接测试超时为 15 秒，打开连接超时为 20 秒；网络抖动较大时会表现为超时。

提示 NOAUTH / WRONGPASS / 认证失败

  • 确认密码正确；编辑已有连接时密码框留空表示沿用旧密码，不会清空。
  • Redis 6+ 启用 ACL 时，同时填写用户名与密码；未启用 ACL 时用户名留空。
  • ACL 用户可能被限制只能访问特定键或命令，连接成功但读取失败时应检查 ACL 规则。
  • 哨兵模式需要分别配置「哨兵密码」与 Redis 数据节点密码。

TLS 握手失败

  • 确认服务端确实启用了 TLS，而不是普通 TCP 端口。
  • 自签证书请填写「CA 证书」，不要直接勾选「跳过证书校验」。
  • 双向 TLS 需要同时提供客户端证书与私钥。
  • 证书域名与连接地址不一致时，填写 SNI 服务器名。

SSH 隧道失败

  • 先确认能用同一账号、同一私钥通过系统 SSH 客户端登录跳板机。
  • 私钥需为常见的 OpenSSH / PEM 格式；带口令的私钥填写「私钥口令」。
  • Redis 地址必须是跳板机能访问的地址；填本机地址通常无法连通。
  • 当前版本不校验 SSH 主机指纹，无法通过错误提示发现跳板机被替换，请自行确认网络可信。

哨兵连接失败

  • 检查 master name 是否与哨兵配置一致。
  • 至少一个哨兵地址可达；多个地址用逗号分隔。
  • 哨兵启用认证时填写哨兵用户名 / 密码，注意与数据节点密码区分。
  • 主从切换期间可能短暂失败，稍后重试或等待心跳重连。

集群为什么不能选 DB

Redis Cluster 只支持 DB 0，这是服务端限制。连接表单会将 DB 锁定为 0， 顶部显示「DB 0 · Cluster」。

修改连接配置后没有生效

已打开的连接使用打开时的配置快照。修改地址、密码、TLS、只读等设置后， 需要先「断开」再「连接」。仅保存不会影响正在运行的连接。

断线后不再自动重连

后台每 5 秒 PING 一次，断线后按退避策略重试，最多约 30 次。超过后会停止自动重连， 避免对故障实例持续施压。请检查网络 / 实例状态后手动重新连接。

使用问题

为什么写操作被拦截

当前连接开启了只读模式。界面会隐藏 / 禁用写入口，控制台与后端也会拒绝写命令和未知命令。 确认目标实例与权限后，编辑连接关闭只读并重新连接。

危险命令为什么一直要求确认

FLUSHALL、CONFIG SET、SHUTDOWN 等命令默认被拦截， 需要手动输入命令名才能执行。当前版本控制台始终执行该确认，设置中的开关不会跳过它。

为什么不提供 KEYS 全量查询

KEYS 会遍历整个键空间并阻塞 Redis，生产环境风险很高。 RedisLens 的键列表、树与全局搜索都使用 SCAN。 如果确实需要执行 KEYS，控制台会把它作为阻塞命令要求二次确认。

监控图表没有数据

  • 连接刚打开时只有首帧，QPS 等速率要等第二帧（默认 10 秒后）才出现。
  • 连接已断开或关闭时采样停止。
  • 采样间隔设置过大时曲线点会很稀疏；可在设置中调小。
  • 集群模式只采样其中一个节点，不代表全集群。
  • 应用重启或断开连接会清空历史。

为什么 List / Set / ZSet 只显示 500 个元素

为避免超大集合撑爆界面与内存，值查看器对 List / Set / ZSet 只加载前 500 个， Stream 只加载前 200 条。Hash 使用 HGETALL 返回全部字段。 更大范围请使用控制台的 LRANGE、SSCAN、ZRANGE、 XRANGE 按需读取。

JSON 类型打不开

JSON 类型依赖服务端加载 RedisJSON 模块。 没有模块时，Redis 会把这类键视为其他类型或直接报错；请先在服务端安装并加载模块。

控制台里 MULTI / EXEC 为什么不生效

控制台每次执行都从连接池取连接，MULTI 与后续命令不保证在同一物理连接上。 需要事务语义时，请使用 Lua 脚本、Redis Functions，或在业务客户端中实现。

导入导出与删除

导入提示 not a RedisLens export file

导入只接受 RedisLens 导出的 JSON（JSONL）文件，文件第一行必须是 {"format":"RedisLens-export",...}。CSV 清单不能导入。

部分键导入失败

  • DUMP / RESTORE 受 Redis 版本与模块影响；目标版本过低或缺少模块会导致失败。
  • 覆盖未勾选时，已存在的键会被跳过，属于预期行为。
  • 换行、编码或手工编辑可能破坏 JSONL 结构，导致后续行无法解析。
  • 报告中的失败计数是真实的失败条数；RESTORE 失败后仅 string / json 会尝试用可读值回退重建。
  • 回退重建使用无过期写入，可能丢失原 TTL；跨实例迁移应以 RESTORE 成功为准。

批量删除只删了一部分

批量删除针对「本次预览中的键」执行，预览最多保留 1000 个样本。如果匹配总数超过 1000， 实际删除的是这 1000 个样本 500 个一批地删除。请缩小匹配模式分批处理， 或在控制台按明确键名删除。详见 批量删除。

回收站为空 / 无法恢复

  • 回收站只保存通过界面删除的键，且仅存在于当前连接的内存中。
  • 关闭连接、切换实例或退出应用会清空回收站。
  • 容量为 100 条 / 64 MB，超出后最旧条目被淘汰。
  • 恢复会覆盖同名键，并保留删除时的 TTL。

导出大库时卡住或超时

导出会先把匹配记录收集到内存再写文件，单次操作超时为 10 分钟。 超大键空间请按前缀分批导出，并避免同时执行大 Key 扫描或批量删除。

配置与数据目录

忘记已保存的密码怎么办

出于安全设计，应用不回显已保存密码，也不提供找回。请编辑连接并输入新密码； 如果密码未知，需要在 Redis 侧重置。凭据加密与机器绑定，无法通过复制配置绕过。

换电脑后所有连接都无法认证

key.bin 与机器标识共同派生密钥，复制到新机器后旧密文无法解密。 连接配置仍在，但密码为空；逐条编辑并重新输入密码即可。

config.json 损坏

启动时如果 config.json 不是合法 JSON，应用会把它改名为 config.json.corrupt.YYYYMMDDhhmmss 备份，然后以空配置启动。 可从备份中恢复连接字段，但密码密文仍受机器绑定限制。

启动后窗口空白 / 无法显示界面

安装 Microsoft Edge WebView2 Runtime（Evergreen）后重试。Windows 10 / 11 通常已内置，但精简系统或服务器版可能缺失。

卸载后配置还在

卸载程序只移除应用文件，不会删除 %APPDATA%\RedisLens。 如需彻底清理，请手动删除该目录；其中包含加密凭据与审计日志。

其他

数据会上传到云端吗

不会。应用只连接你配置的 Redis、SSH 与哨兵地址，不包含遥测或云端同步。

支持 macOS / Linux 吗

当前正式发布仅面向 Windows 10 / 11 x64。源码基于 Wails，理论上可移植， 但未提供其他平台的构建与测试。

支持哪些 Redis 版本

兼容 Redis 4.0 – 7.x。低版本没有 SCAN TYPE 时会降级为普通 SCAN + 客户端类型过滤；分段 INFO 不可用时会回退为全量 INFO。 RedisJSON、ACL 等能力取决于服务端版本与模块。
