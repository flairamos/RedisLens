为生产环境的日常操作而设计

不是把 Redis 命令包装成按钮，而是在每一个高风险动作前加上可验证的边界。

安全默认

键浏览只走 SCAN 渐进游标，不触发 KEYS 全量阻塞； 只读模式在 UI 与后端双重拦截写操作；危险命令必须二次确认并写入审计。

一站式工作台

从连接管理与键空间编辑，到 INFO 监控、大 Key 分析、慢查询、Pub/Sub 与 JSON 迁移，减少在 redis-cli、监控面板和临时脚本之间来回切换。

本地优先

连接凭据以 AES-256-GCM 加密后落盘，密钥由随机主密钥与机器标识派生； 审计日志、回收站与配置都留在本机，不依赖任何云端服务。

从下载到连上第一个实例

三步完成首次连接。完整说明见 安装与首次连接。

  1. 下载并安装 从 GitHub Releases 获取 RedisLens-amd64-installer.exe（安装包）或 RedisLens.exe（便携版）。 系统要求 Windows 10 / 11 x64，WebView2 运行时随 Windows 提供。
  2. 登记一个 Redis 实例 打开「连接管理」→「新建连接」，填写名称、地址与端口；按需配置分组、密码、SSH 隧道、TLS 或哨兵 / 集群模式，然后点「测试连接」验证。
  3. 连接并开始工作 保存后点击「连接」。连接成功会启动心跳探活与 INFO 采样；左侧键空间树、监控仪表盘、 控制台与分析模块随之可用。

兼容性与技术栈

面向 Windows 桌面环境，兼容 Redis 4.0 至 7.x，并对低版本能力差异做自动降级。

运行环境

  • Windows 10 / 11 x64，使用系统 WebView2 渲染界面
  • Redis 4.0 – 7.x；5.x 无 SCAN TYPE 时自动降级为客户端类型过滤
  • 多段 INFO 不可用时自动回退为全量解析
  • RedisJSON 相关能力需服务端加载 RedisJSON 模块

技术构成

Go 1.26 与 Wails v2 承载桌面外壳和 Redis 访问层，Vue 3 + TypeScript + Vite 构建前端，ECharts 5 绘制监控图表，go-redis v9 负责协议与集群 / 哨兵客户端。
