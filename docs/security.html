安全与审计

RedisLens 是本地桌面工具，安全边界主要由「本机账号、Redis 访问权限与网络路径」决定。 产品在凭据存储、只读模式、危险命令与审计留痕上提供默认防护，但不会替代服务端的 ACL、TLS 与网络隔离。

安全模型

  • 本地优先：连接配置、凭据、审计日志与回收站都在本机，不向任何云端服务上传数据。
  • 最小权限：建议为 RedisLens 使用独立 ACL 账号，按环境授予只读或有限写权限。
  • 纵深防御：只读模式在界面与后端双重校验；危险命令在客户端拦截并强制确认；所有操作写入审计。
  • 不替代服务端安全：Redis 自身的 requirepass / ACL、TLS、防火墙与 protected-mode 仍需正确配置。

凭据加密

Redis 密码、哨兵密码、SSH 密码与 SSH 私钥口令不会以明文落盘。保存时使用 AES-256-GCM 加密，密文以 AESGCM1: 前缀存入 config.json。

环节实现
数据密钥 由 32 字节随机主密钥（key.bin）与机器标识经 HKDF-SHA256 派生。
机器绑定 Windows 下读取 Machine GUID；读取失败时回退为主机名。把配置复制到另一台机器无法解密。
加密算法 AES-256-GCM，12 字节随机 nonce，认证标签随密文一起保存。
文件权限 配置目录 0700，config.json 与 key.bin 以 0600 创建，仅当前用户可读。
界面回显 连接列表与编辑表单不回传已保存密码；编辑时留空表示沿用原密码。
换机、重装系统与密钥丢失
  • 复制 %APPDATA%\RedisLens 到另一台机器后，连接仍在，但密码无法解密，需要重新输入。
  • 重装系统可能改变 Machine GUID，导致原有密文失效。
  • 删除或损坏 key.bin 后，已保存的密码不可恢复；应用会生成新密钥，旧密文无法解密。
出现这些情况时，Redis 数据本身不受影响，重新编辑连接并输入密码即可。

数据目录与权限

配置目录
%APPDATA%\RedisLens
连接与设置
config.json（机密字段为密文）
主密钥
key.bin（32 字节，0600）
审计日志
audit\audit-YYYY-MM.jsonl（0600，按月起文件）
本地日志
logs\redislens.log（开启本地日志开关时写入）
损坏备份
config.json.corrupt.YYYYMMDDhhmmss（解析失败时自动改名备份）
  • 应用不会把 Redis 数据复制到配置目录，回收站除外，且回收站仅存在于内存。
  • 备份数据目录时，请把它当作包含敏感信息的文件处理；即使密码加密，连接拓扑与审计内容仍然敏感。

只读模式

只读模式是连接级策略。开启后，前端隐藏 / 禁用写入口，后端在 DeleteKeys、SetTTL、SetString、Import、 Publish、RecycleRestore 等写路径执行前再次校验。

  • 控制台中写命令与未知命令被拦截，并返回明确原因。
  • 危险命令即使确认也不会绕过只读限制。
  • 读取、监控、拓扑、慢查询、审计查询不受影响。
  • 只读是客户端约束，不能阻止其他客户端写入；真正的只读保障应使用 Redis ACL。

危险命令拦截

命令按读、写、危险、阻塞四类建模，并支持子命令覆写（例如 CONFIG GET 只读， CONFIG SET 危险）。控制台执行前会分类；危险与阻塞命令必须二次确认。

风险类别示例处理
清空 / 覆盖数据 FLUSHDB、FLUSHALL、SWAPDB、RESTORE、MIGRATE 拦截 → 输入命令名确认 → 审计 danger。
服务与配置 SHUTDOWN、CONFIG SET、CONFIG RESETSTAT、DEBUG、SLAVEOF / REPLICAOF 同上。只读子命令（如 CONFIG GET）正常执行。
脚本 / 函数 / 集群 / ACL SCRIPT FLUSH、FUNCTION FLUSH、CLUSTER SETSLOT、ACL SETUSER 按子命令识别；写操作需确认，查询操作放行。
阻塞 / 流式 KEYS、MONITOR、SUBSCRIBE 提示会独占连接，确认后执行；建议改用 SCAN 或发布订阅页面。
普通写 SET、DEL、HSET、EXPIRE 正常执行并审计；只读模式下拦截。
黑名单不是完备的
命令分类基于内置注册表，未覆盖的自定义模块命令会按「写」处理： 只读模式拦截，非只读模式放行。不要把拦截列表当作完整的安全策略。

审计日志

审计日志以 JSONL 追加写入 audit\audit-YYYY-MM.jsonl，按自然月轮转； 应用启动时删除超过 90 天的文件。界面提供最近 500 条记录的查询与筛选。

字段说明
time操作时间（RFC 3339）。
connId / connName连接标识与名称。
categoryconnection、command、dangerous、key_edit、key_delete、export、import、analysis。
action动作名，如 SET、DELETE、IMPORT。
target键名、命令摘要或文件名。
detail补充信息，如字段名、键数量、失败原因。
resultok、error、blocked。
levelinfo、warn、danger。
  • 危险命令被拦截时记录 blocked / warn；用户确认执行后记录 danger。
  • 键删除、移除 TTL 等操作记录为 warn，便于回溯高风险动作。
  • 审计日志是本地普通文件，没有数字签名或防篡改机制；有合规需求时请实时采集到集中日志系统。
  • 审计查询本身不会写入审计，避免自我放大。

回收站

删除键时，如果开启备份（界面默认开启），会先 DUMP 当前值并记录 PTTL，然后执行 UNLINK。回收站按连接隔离。

属性说明
容量最多 100 条或 64 MB，超出后自动淘汰最旧条目。
存储位置进程内存，不落盘。
生命周期跟随连接：关闭连接或退出应用即清空。
恢复方式RESTORE REPLACE，保留删除时的 TTL；永久键以 0 TTL 恢复。
覆盖行为如果同名键已存在，恢复会覆盖它。
审计删除记录 key_delete；恢复记录 RESTORE。
回收站不是备份系统
它只存在于内存，容量有限，且关闭连接即丢失。需要可靠回滚时，请在删除前使用 JSON 导出做完整备份。

SSH 与 TLS 边界

  • SSH 隧道使用 x/crypto/ssh，支持密码与私钥认证。
  • 不校验 SSH 主机密钥：没有 known_hosts 管理，无法发现中间人替换跳板机。只在可信网络中使用，或通过堡垒机与网络策略控制。
  • TLS 最低版本为 1.2；指定 CA 时使用该 CA 校验服务端证书；开启「跳过证书校验」会关闭身份验证，仅建议测试环境使用。
  • SSH 与 TLS 解决的是传输安全，不改变 Redis 的认证与授权模型。

本地日志

开启「本地日志开关」后，应用运行日志追加写入 logs\redislens.log，包含连接重连等诊断信息，不记录密码或键值。 关闭开关会立即停止写入。日志文件没有自动轮转，长期运行请自行清理。

上线前检查清单

  • 生产连接使用独立 ACL 账号，默认开启只读模式。
  • 远程访问启用 TLS 或 SSH 隧道，并验证证书 / 跳板机可信。
  • 不在多人共用 Windows 账号的机器上保存生产凭据。
  • 为 %APPDATA%\RedisLens 做受控备份，并按敏感数据管理。
  • 定期检查审计日志，确认没有意外的危险命令或批量删除。
  • 大批量删除前先 JSON 导出，不依赖回收站作为唯一回滚手段。
